# DSAP Lab Assignment 2 Report

Generates the DSAP Lab Assignment 2 PDF report.

## Run

From the repository root:

```bash
uv run python lab2-report-generator/generate_report.py
```

Final PDF:

```text
lab2-report-generator/output/final-report.pdf
```

Edit `data.json` to update the student name, roll number, date, deadline, title, department, and logo path.
